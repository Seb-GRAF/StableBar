The light follows your pointer.Drag sideways to steer the light.

Or click the hill or the sea.Or tap the hill or the sea.

Edit the bar where it is.

Drag widgets between positions, take one off with −, and add one with + right where it should go. Changes save as you go, with Undo.

Every widget, style and popup is also a setting, per display and per kind of screen, in Settings or in plain JSON. StableBar applies the file when you save it, and keeps the last working bar if a change is invalid.

The keeper rearranges things when bored.

Themes

Choose a theme during setup, cycle through them on your own bar with Try Themes…, or get more from the Store. Save as Theme… turns your own look into one.

Pick one here and the bar at the top changes with it.

Any script is a widget.

A widget can run any command that prints text or a JSON object. Refresh it on a timer or on events, and give it a popup with graphs, lists and controls.

widgets/disk.shsh
#!/bin/sh
used=$(df -h / | awk 'NR == 2 { print $5 }')
printf '{"text":"%s","icon":"internaldrive"}' "$used"
