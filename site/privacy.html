Privacy Policy

Last updated on 29 October 2026.

StableBar is a free, open-source app by Sebastien Graf and Steve Mendes Reis. It has no account and no analytics, and we don't collect personal data.

On your Mac

Your configuration, widgets and scripts stay in files on your Mac. What the bar shows, such as calendar events, CPU, memory, battery and network use, is read on your Mac and never sent anywhere by StableBar.

StableBar asks for two macOS permissions, and uses them only on your Mac:

  • Accessibility, to show the frontmost app's menus and to move windows clear of the bar.
  • Calendars, only for the meetings and agenda widgets.

What the app sends

On its own, StableBar connects only to GitHub:

  • Updates. It checks GitHub for a new version shortly after launch and then every few minutes, and downloads an update when you choose to install it. Turn the checks off in Settings → General → Updates.
  • The store. Packages loads the store's listing and the packages you install from GitHub. Package sources you add yourself load from the addresses you give.
  • Bug and crash reports. Reporting a bug or a crash opens a prefilled issue on GitHub in your browser. Nothing is sent until you submit it there, and you can edit or remove anything first.

Like any website, GitHub receives your IP address with these requests. The GitHub Privacy Statement covers how GitHub handles them.

Widgets and packages run commands on your Mac, and the ones you add can contact other services, such as a weather service. Before you install a package, StableBar lists the commands, hosts and permissions it uses. If you run StableBar triage, it hands your terminal to Claude Code or Codex, which follow their providers' policies.

The website

stablebar.app is hosted on GitHub Pages. It sets no cookies and has no analytics or third-party scripts, and it serves its fonts itself. Your choice of light or dark mode is saved in your browser. GitHub receives your IP address when you visit.

Changes and contact

If this policy changes, we update this page and its date. Its history is on GitHub.

Questions about privacy: contact@stablebar.app.
