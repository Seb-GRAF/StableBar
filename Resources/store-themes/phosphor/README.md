# Phosphor

An amber CRT terminal, set in Monaco, which comes with macOS. In the dark appearance, amber text
glows on black; in the light one, brown ink sits on printout paper.

Highlights have square corners, and the focused workspace is in reverse video.

This is the theme that came with StableBar, unchanged and under the same ID, `phosphor`, so edits
you made to Phosphor in Settings apply to it too.
