# Nord

A slim strip, 30 points tall, in colors from the Nord palette: Snow Storm in the light appearance,
Polar Night in the dark one, with Frost for the accent. It's set in Avenir Next, which comes with
macOS.

A short Frost dash under a workspace marks the focused one, and a dimmer dash marks a workspace
shown on another screen.

This is the theme that came with StableBar, unchanged and under the same ID, `nord`, so edits you
made to Nord in Settings apply to it too.
