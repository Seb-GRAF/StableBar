# Notch

A pure black strip in both appearances, with white text and a cyan accent, so the bar blends into a
MacBook's notch. Widgets sit on the strip without tiles of their own, and popups are black too.

The focused workspace's number turns white; the others stay gray.

This is the theme that came with StableBar, unchanged and under the same ID, `notch`, so edits you
made to Notch in Settings apply to it too.
