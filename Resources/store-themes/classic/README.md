# Classic

StableBar's original look: each widget sits on its own floating tile, with a soft border and shadow,
over a clear bar, in light or dark with a blue accent. The focused workspace is a blue pill.

Classic is the look StableBar draws when no theme is selected, which it listed as Built-in. Its
configuration repeats those values, the fallback under every theme, so selecting Classic looks the
same as selecting no theme.
