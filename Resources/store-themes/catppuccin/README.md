# Catppuccin

Colors from the Catppuccin palette, Latte in the light appearance and Mocha in the dark one. Widgets
sit in rounded pills on a solid Crust strip, and popups take the palette's Base color.

The focused workspace is a Mauve pill.

This is the theme that came with StableBar, unchanged and under the same ID, `catppuccin`, so edits
you made to Catppuccin in Settings apply to it too.
