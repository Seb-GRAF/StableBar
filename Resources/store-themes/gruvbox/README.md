# Gruvbox

A strip in colors from the Gruvbox palette, light and dark, set in American Typewriter, which comes
with macOS. Red, orange and yellow 70s stripes run along the bottom of the strip.

The focused workspace is an orange block.

This is the theme that came with StableBar, unchanged and under the same ID, `gruvbox`, so edits you
made to Gruvbox in Settings apply to it too.
