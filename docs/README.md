# StableBar user guide

StableBar reads one JSON configuration, by default `~/.config/stablebar/config.json`, and is controlled from its menu-bar icon, the Settings window and the `StableBar` command line. This guide documents every feature and configuration option.

| Page | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Installing, setup, the first launch, updates and keeping windows clear of the bar |
| [Configuration](configuration.md) | The configuration file, includes, templates, overrides, tokens and profiles |
| [Styles and states](styling.md) | Widget styles, hover and open states, presentation roles and data states |
| [Themes](themes.md) | The included themes, making and sharing your own, and Liquid Glass |
| [Built-in widgets](widgets.md) | Workspaces, app menus, tooltips and mouse actions |
| [Create a widget](create-a-widget.md) | Script output, events, widget layouts, animation and controls on hover |
| [Shared providers and native data](providers.md) | Data sources shared by several widgets, system data and the calendar |
| [Custom popups](popups.md) | Popup layouts, blocks and controls |
| [Displays and layout](layout.md) | Notch placement, screen setups, overflow and groups |
| [Packages and the store](packages.md) | Installing, reviewing, writing and publishing packages |
| [Settings](settings.md) | Each section of the Settings window |
| [Command-line controls](command-line.md) | Querying and editing the running bar, and sending events |

The [examples](../examples) folder holds working setups, and [stablebar.schema.json](../stablebar.schema.json) describes every configuration property.
